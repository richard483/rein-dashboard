What is Karasu Auth?

A comprehensive authentication and authorization service built with Go.

🔐 Authentication

User registration, login, logout with session management

📧 Email Verification

Verify user emails with secure token-based verification

🔑 Password Reset

Secure password reset via email with custom redirect URLs

⚡ Redis Caching

Session caching for improved performance

API Endpoints

Public Endpoints

  • POST /auth/register - Register new user
  • POST /auth/login - User login
  • POST /auth/verify-email - Verify email token
  • POST /auth/resend-verification - Resend verification email
  • POST /auth/forgot-password - Request password reset
  • POST /auth/reset-password - Reset password with token
  • POST /auth/refresh - Refresh access token

Protected Endpoints

  • POST /auth/change-password - Change password (requires auth)
  • GET /auth/sessions - Get active sessions
  • DELETE /auth/sessions/:id - Logout specific session
  • POST /auth/logout/all - Logout all devices

Security Features

  • Password hashing with bcrypt
  • JWT-based access + refresh tokens
  • Rate limiting on login endpoints
  • Email verification required before account activation
  • Password reset tokens expire in 30 minutes
  • Session invalidation on password change
  • Redis session caching with automatic invalidation
  • HTTPS enforced in production
